     Script A: Header Heatmap (analyze_header_deps.py)

     Purpose: Find which headers are the biggest blockers for actor compilation.

     Logic:
     1. Walk through src/actor/*.c files
     2. Parse #include statements from each file
     3. Count occurrences of each header across all actors
     4. Rank headers by "blocking count"

     Output: Ranked list showing header impact:
     Header Dependency Report
     ========================
     m_common_data.h    - Used by 129 actors
     m_player_lib.h     - Used by 101 actors
     m_collision_bg.h   - Used by 87 actors
     m_field_info.h     - Used by 76 actors
     sys_matrix.h       - Used by 68 actors
     ...

     Implementation:
     #!/usr/bin/env python3
     """Analyze header dependencies across actor files."""

     import os
     import re
     from collections import Counter
     from pathlib import Path

     ACTOR_DIR = "src/actor"
     INCLUDE_PATTERN = re.compile(r'#include\s+[<"]([^>"]+)[>"]')

     def scan_includes(filepath):
         """Extract all #include statements from a C file."""
         includes = []
         with open(filepath, 'r', errors='ignore') as f:
             for line in f:
                 match = INCLUDE_PATTERN.search(line)
                 if match:
                     includes.append(match.group(1))
         return includes

     def main():
         header_counts = Counter()
         actor_files = list(Path(ACTOR_DIR).glob("*.c"))

         for actor_file in actor_files:
             includes = scan_includes(actor_file)
             header_counts.update(includes)

         print("Header Dependency Report")
         print("=" * 50)
         for header, count in header_counts.most_common(30):
             print(f"{header:40} - Used by {count} actors")

     if __name__ == "__main__":
         main()

     Script B: Profile Linker Check (analyze_actor_profiles.py)

     Purpose: Verify which actors are "linker-ready" vs "broken," with focus on TITLE_DEMO scene.

     Logic:
     1. Parse src/game/m_scene.c or scene tables to find actors spawned in TITLE_DEMO
     2. For each actor .c file, find the ACTOR_PROFILE struct
     3. Extract function pointers: ct_proc, dt_proc, mv_proc, dw_proc, sv_proc
     4. Check if those functions are defined in the file
     5. Report "Ready to Link" vs "Missing Functions"
     6. Prioritize TITLE_DEMO actors in the output
